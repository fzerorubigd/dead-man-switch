# pubkey/

`operator.asc` is the **project-specific** GPG public key for the
dead-man-switch — a dedicated keypair for this repo, *not* anyone's
personal key. It is the encryption target for every death-key blob (the
recipient list and each death-action payload).

A public key is safe to commit — it can only *encrypt*. The matching
**private** key is never stored in the repo; it lives only in the
`GPG_PRIVATE_KEY` GitHub secret and is imported at runtime by the
trigger layer. The keypair was generated by the operator locally, so the
private key has never left the operator's machine except into the GitHub
secret.

- Key: `life-tracker dead-man-switch <lifetracker+nokey@rubi.gd>`
- Fingerprint: `2E61 1588 9A19 1849 B2AF  DBFC DFE1 1A73 9F64 69C3`
- Algorithm: EdDSA (ed25519) sign + ECDH (cv25519) encrypt, no passphrase, no expiry.

## Usage

`lt-crypt encrypt` defaults to `--pubkey pubkey/operator.asc`:

```sh
lt-crypt encrypt --in recipients.json --out recipients.gpg
```

The resulting `*.gpg` ciphertext is committed to the repo; only the
trigger layer (holding the `GPG_PRIVATE_KEY` secret) can decrypt it.

## Rotating the key

Generate a fresh passphrase-less keypair locally, replace `operator.asc`
with the new public key, re-encrypt every committed blob to it, and
update the `GPG_PRIVATE_KEY` secret from the new private key:

```sh
gpg --batch --gen-key   # %no-protection, Expire-Date: 0
gpg --armor --export             <key-id> > pubkey/operator.asc
gpg --armor --export-secret-keys <key-id> | gh secret set GPG_PRIVATE_KEY
```
